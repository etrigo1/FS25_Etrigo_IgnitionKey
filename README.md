# Ignition Key (FS25_Etrigo_IgnitionKey)

Farming Simulator 25 mod: an ignition key on the keyboard, using the normal engine start key.

## How it works

| Engine | Key | Result |
|---|---|---|
| Off | tap | Ignition on: dashboard lights up, engine stopped |
| Off | hold | Turns the key all the way: ignition, then start |
| Ignition | tap | Ignition off |
| Ignition | hold | Starts the engine |
| Starting | release | Keeps cranking until the engine catches, like the real key |
| Running | tap | Stops the engine |

- Leaving the vehicle with the ignition on switches it off.
- Works only with **automatic engine start disabled** in the game settings.
- With the hardware ignition lock connected, or a helper working, the game works as normal.
- Multiplayer supported.

## Advanced Damage System (ADS)

Works alongside [FS25_AdvancedDamageSystem](https://github.com/id577/FS25_AdvancedDamageSystem-dev). The key is shared, so the ADS hard start, battery and starter failures still apply while you hold the key.

## Installation

Put `FS25_Etrigo_IgnitionKey.zip` in your `mods` folder. The zip contains `modDesc.xml`, `icon_ignitionKey.dds` and the `scripts` folder.

# Chave de Ignição (PT)

Chave de ignição no teclado, na tecla normal de arranque do motor.

- **Toque:** liga ou desliga a ignição (o painel acende, o motor fica parado).
- **Manter premido:** roda a chave e arranca. Depois de começar o arranque podes largar, como na chave real.
- **Toque com o motor a trabalhar:** desliga o motor.
- **Sair do veículo** com a ignição ligada desliga-a.
- **Arranque automático:** só funciona com ele desligado. Com o canhão de ignição físico ligado, ou com um trabalhador a trabalhar, o jogo funciona como de origem.
- **ADS:** funciona ao lado do Advanced Damage System. O arranque difícil e as avarias de bateria e de motor de arranque do ADS continuam a funcionar.
